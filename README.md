# GlowUp Salon Website (Demo)

A modern, responsive demo website for salon businesses in India.  
Designed with pastel colors, elegant typography, and Instagram‑ready layouts to appeal to younger, trend‑focused clients.

---

## ✨ Features
- **Responsive Design**: Mobile‑first layout using Flexbox and CSS Grid.
- **Modern Aesthetic**: Pastel pink, cream, and lavender palette with clean typography.
- **Hero Section**: Full‑width banner with overlay and call‑to‑action button.
- **Services Section**: Card‑based layout showcasing salon services with INR pricing.
- **Gallery**: Image grid for bridal looks, hair styling, nail art, and facials.
- **Contact Section**:
  - WhatsApp integration for quick booking.
  - Simple contact form with demo submission.
- **Animations**: Smooth fade‑ins, hover effects, and micro‑interactions.
- **Sticky Header**: Easy navigation across sections.

---

## 🛠️ Tech Stack
- **HTML5** for structure
- **CSS3** for styling (variables, transitions, animations)
- **JavaScript** for interactive demo alerts

---

## 🚀 Getting Started
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Replace placeholder images and text with your salon’s real content.
4. Update contact details (phone number, WhatsApp link, location).

---
